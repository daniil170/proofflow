# Nordic Tech — fictional B2B demo fixture

Этот материал создан только для локального технического демо ProofFlow. Компания, диалог и результат вымышлены. Fixture нельзя публиковать как реальный клиентский кейс или использовать как подтверждение спроса.

## Содержимое

- `mock-chat.svg` — редактируемый исходник изображения.
- `mock-chat.png` — входной файл для pipeline.
- `demo-output.md` — ожидаемый проверенный результат.

## Локальный запуск

Из папки `functions`:

```bash
USE_MOCK_ADAPTERS=true npm run local -- ../test-materials/nordic-tech 'Nordic Tech — fictional demo'
```

При явном mock-режиме внешние AI API не используются.

## Ожидаемая проверка

- Статус: `review`.
- Цитата подтверждена дословно: да.
- Цифры метрики найдены: да.
- Неподтверждённые цитаты: нет.
- Неподтверждённые метрики: нет.
- Поля `problem` и `solution`: отсутствуют, потому что исходный диалог их не содержит.
